## Implemented behavior

1. **Review Criteria Setup Form (`frontend/src/features/review-setup/CriteriaEditor.tsx`):**
   - Editable review question and structured PICO fields (Population, Intervention, Comparator, Outcome).
   - Interactive screening rules checklist with rationale, category tags, and inclusion/exclusion badges.
   - Saves immutable criteria versions via `api.criteria.create()`, displaying version sequence and SHA-256 fingerprint badge.

2. **Grouped Boolean Query Builder (`frontend/src/features/search/QueryBuilder.tsx` & `astCompiler.ts`):**
   - Supports AND / OR / NOT inter-group and intra-group operator nesting with quote-wrapped phrase compilation.
   - Validates ISO publication dates (YYYY, YYYY-MM, YYYY-MM-DD).
   - Generates compliant `QueryASTNode-Input` AST payloads sent to `POST /api/v1/workspaces/{workspace_id}/queries`.
   - Renders live human-readable preview of the compiled AST.
   - Source selection: PubMed and Europe PMC checkboxes with validation.

3. **Transparent Search Count Acquisition & Execution Comparison:**
   - Sequential count runner calling `POST /api/v1/queries/{query_id}/searches` per selected source database.
   - Comparison view displaying source badge, hit count, execution timestamp, and translated provider query string.
   - Checkboxes allow selecting specific search executions for import approval.
   - Displays NCBI and Europe PMC attribution notice and legal disclaimer.

4. **Approved Ingestion Workflow & Durable Job Poller (`frontend/src/features/runs/ImportWorkflow.tsx`):**
   - Import cap configuration (default: 200).
   - Client-side idempotency key generation (`crypto.randomUUID()`) to prevent duplicate job creation upon repeated submission.
   - Calls `POST /api/v1/workspaces/{workspace_id}/imports` to initiate background literature fetching.
   - Exponential backoff polling loop (1s to 5s) against `GET /api/v1/jobs/{job_id}`.
   - Shows stage, processed items, total items, progress bar, and error details (handling 429 and retryable server errors).
   - Cancel job action calling `POST /api/v1/jobs/{job_id}/cancel`.
   - Persists active job ID in `sessionStorage` so refreshing the browser preserves background job tracking state.

5. **Page Orchestration & Unit Tests:**
   - Integrated into `frontend/src/features/search/QueryBuilderPage.tsx`.
   - 10 unit tests in `frontend/src/tests/search_import.test.ts` verifying date validation, AST compilation, and human-readable string rendering. 13/13 vitest tests passing.
   - Production bundle built at 110KB gzip with 0 TypeScript errors (`tsc --noEmit`).
