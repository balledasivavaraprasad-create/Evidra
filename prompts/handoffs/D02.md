## Implemented behavior

1. **Question & Criteria Version Persistence (`backend/app/main.py`):**
   - Implemented `POST /api/v1/workspaces/{workspace_id}/criteria` returning 201 Created.
   - Enforces monotonic version sequencing per workspace (`sequence` starting at 1).
   - Serializes structured PICO descriptions and criterion definitions to deterministic JSON.
   - Calculates immutable SHA-256 `content_hash` over question and serialized criteria.

2. **Immutable Query Versioning & Boolean AST Translation (`backend/app/sources/translator.py`):**
   - Implemented `POST /api/v1/workspaces/{workspace_id}/queries` returning 201 Created.
   - Recursive Boolean AST translator supporting `AND`, `OR`, `NOT` grouping and field bindings.
   - **PubMed Syntax Translation (`build_pubmed_query`):** Translates term nodes to `"<term>"[Title/Abstract]`, formats date bounds to `YYYY/MM/DD[dp]`, and handles nested grouping parentheses.
   - **Europe PMC Syntax Translation (`build_europepmc_query`):** Translates term nodes to `TITLE_ABS:"<term>"`, formats date ranges to `FIRST_PDATE:[YYYY-MM-DD TO YYYY-MM-DD]`, and preserves search operators.

3. **PubMed E-Utilities Adapter (`backend/app/sources/pubmed.py`):**
   - Implemented `PubMedAdapter` with `search_count`, `fetch_ids_for_execution`, and `fetch_records_by_pmids`.
   - Rate-limiting mechanism (< 3 req/sec with minimum 350ms delay between NCBI calls).
   - Configured NCBI parameters: `tool=EvidraReviewEngine`, `email=evidra-review@example.org`.
   - XML parsing hardened via `defusedxml.ElementTree`:
     - Preserves collective author names (`CollectiveName`) and standard author lists (`LastName ForeName`).
     - Extracts structured abstract sections (`BACKGROUND`, `METHODS`, `RESULTS`, `CONCLUSIONS`).
     - Extracts journal titles, publication years (handling both standard year and `MedlineDate`), pagination, languages, and DOIs (from `ELocationID` and `ArticleIdList`).
     - Calculates deterministic SHA-256 fingerprint over title and normalized abstract.

4. **Europe PMC REST Adapter (`backend/app/sources/europepmc.py`):**
   - Implemented `EuropePMCAdapter` with `search_count` and `fetch_page`.
   - Cursor progression using `cursorMark` with loop detection (`nextCursorMark == cursor`).
   - Explicit synonym expansion parameter passing (`synonym=true|false`).
   - Source namespace retention (`med`, `pmc`, `ppr`, `cba`, `ctx`).
   - Rate limit detection (HTTP 429) extracting `Retry-After` header.

5. **Test Fixture Transport (`backend/app/sources/fixture.py`):**
   - Fully isolated, deterministic fixture transport serving synthetic records from `synthetic_records.py`.
   - Gated strictly by `settings.ci_offline`, `settings.source_mode == "fixture"`, or `settings.app_env == "test"`.

6. **Durable Background Jobs Service (`backend/app/services/jobs.py`):**
   - Atomic enqueue with idempotency key enforcement (`request_key`).
   - Reused idempotency key with identical payload returns existing job; changed payload raises HTTP 409 Conflict.
   - Single-worker lease acquisition (`acquire_next_job`) with timeout-based lease expiration.
   - Stage, progress (0.0 to 1.0), and processed item tracking.
   - Job cancellation endpoint `POST /api/v1/jobs/{job_id}/cancel`.

7. **Record Import Pipeline (`backend/app/services/imports.py`):**
   - Implemented `POST /api/v1/workspaces/{workspace_id}/imports` (202 Accepted).
   - Multi-execution approval checking workspace authorization.
   - Safe page-by-page transaction writes without holding DB connections open across HTTP calls.
   - Upsert deduplication on `SourceRecordModel` (`workspace_id`, `source`, `source_namespace`, `external_id`).
   - Non-destructive revision tracking in `RecordRevisionModel`.
   - Query membership associations recorded in `QueryMembershipModel`.

8. **Worker Process (`backend/app/worker.py`):**
   - Synchronous single-job execution entry point (`process_single_job`) for tests and inline runners.
   - Daemon poll loop (`run_worker_daemon`) with configurable polling intervals.
   - Transparent support for test session overrides (`app.dependency_overrides[get_db]`).

9. **OpenAPI Specification & Contract Alignment:**
   - Updated `contracts/openapi.json` to expose implemented routes.
   - Validated schema synchronization with `export_openapi.py --check`.

## Interfaces for downstream owners

- **dev-A (A02):**
  - Use `POST /api/v1/workspaces/{id}/criteria` to save review question and criteria.
  - Use `POST /api/v1/workspaces/{id}/queries` to submit Boolean AST search queries.
  - Use `POST /api/v1/queries/{id}/searches` to execute and count queries on PubMed/Europe PMC.
  - Use `POST /api/v1/workspaces/{id}/imports` to trigger approved literature imports.
  - Poll `GET /api/v1/jobs/{id}` to display progress bar (0 to 100%) and item counts.
- **dev-B (B01):**
  - Records are now durably stored in `SourceRecordModel` and `RecordRevisionModel`. Can query all records for a workspace via DB session or future search endpoints to compute deduplication candidate pairs.
- **dev-C (C01 / C02):**
  - Worker dispatch extensible for invoking automated screening and PICO extraction jobs via `JobKind`.
