## Implemented behavior

1. **Alembic Schema & Persistence (`002_review_services_schema`):**
   - Added tables: `corpus_revisions`, `corpus_queries`, `corpus_members`, `paper_groups`, `group_members`, `group_snapshots`, `group_lineage`, `dedup_edges`, `machine_results`, `review_events`, `pico_annotations`, `review_conflicts`, `exports`.
   - Single migration chain strictly linked from `001_initial_schema`.

2. **Deterministic Corpus Processing Pipeline (`backend/app/services/corpus.py`):**
   - `process_corpus(db, workspace_id, criteria_version_id)`:
     - Gathers imported records across search execution memberships.
     - Executes B01 `DeduplicationEngine` (respecting confirmed/rejected edges and cannot-link constraints).
     - Partitions into immutable `paper_groups` and picks representative records deterministically.
     - Executes B02 `ScreeningEngine` on each representative and caches SHA-256 fingerprinted machine results.
     - Executes C01 `RuleBasedPicoExtractor` to extract PICO spans with half-open Unicode code points.
     - Publishes immutable `CorpusRevisionModel`.
   - `project_effective_group_decision`:
     - Invariant 1: Human review event strictly supersedes machine suggestion.
     - Invariant 2: Active un-resolved conflict yields `CONFLICT`.
     - Invariant 3: Absent human event, machine suggestion reflects in status (`include`, `exclude`, `maybe`).
     - Invariant 4: No decisions/results -> `UNSCREENED`.

3. **Reviewer Decision Persistence & Concurrency (`backend/app/services/review_decisions.py`):**
   - `record_screening_decision`: Append-only event (`SCREEN_DECISION`). Optimistic locking verifies `expected_version == group.row_version` (409 Conflict if mismatched). Exclude requires non-empty reason. Increments `row_version`.
   - `save_pico_annotations`: Verifies text content hash and half-open code-point bounds `[start_cp, end_cp)`. Verifies `text[start:end] == quote`. Allows overlapping spans across labels. Optimistic locking on `row_version`.
   - `record_dedup_override`: Confirms or rejects duplicate candidate pair; records cannot-link constraint.
   - `resolve_group_conflict`: Manually resolves inherited screening divergence on merged groups.

4. **Sanitized CSV Export Service (`backend/app/services/exports.py`):**
   - `export_corpus_studies`: Gathers confirmed included groups (effective status `INCLUDE`). Exports one representative revision per group. Omits unresolved conflicts.
   - Formula injection protection: Sanitizes cells starting with `=`, `+`, `-`, `@`, `\t`, `\r` by prefixing `'` without mutating the database text. Computes SHA-256 checksum and saves file to `backend/data/exports/`.

5. **Evidence Retrieval Repository (`backend/app/services/evidence.py`):**
   - `SqliteEvidenceRepository` conforming to `EvidenceRetrievalPort`.
   - Enforces workspace scoping (cross-workspace queries return empty).
   - Bounds chunks and token contexts.
