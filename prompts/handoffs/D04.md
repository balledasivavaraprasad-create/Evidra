## Implemented behavior

1. **Worker Review Graph Pipeline Wiring (`backend/app/worker.py`):**
   - Implemented `run_corpus_pipeline_job` connecting background jobs (`JobKind.DEDUP`, `SCREEN`, `PICO`) to C02 `run_review_pipeline`.
   - Properly sets `JobState.WAITING_HUMAN` upon LangGraph review interrupt without blocking the worker thread.
   - Updates progress and transitions to `SUCCEEDED` when graph execution completes.

2. **Integration Test Server Launcher (`backend/app/testing/serve.py`):**
   - Strictly refuses execution unless `APP_ENV=test` and `SOURCE_MODE=fixture`.
   - Creates an isolated disposable SQLite database in a temporary directory, runs Alembic migrations, and seeds synthetic SLR workspace `ws-synth-001` with records, revisions, criteria, and deduplication groups.
   - Starts FastAPI application on `127.0.0.1:8000` alongside an in-process background worker daemon.
   - Implements graceful signal handlers (`SIGTERM`, `SIGINT`) and automated temporary directory cleanup.

3. **End-to-End Browser Playwright Suite (`frontend/tests/e2e/level1.spec.ts`):**
   - Automated browser test exercising the live API without mocking browser responses.
   - Verifies health check `/health/ready`, fetches workspace review queue, tests Include action, tests mandatory Exclusion reason modal, and exercises duplicate candidate decision flow.

4. **Integrated CI Stage Activation (`.ci/stages.json`, `scripts/ci/run_checks.py`):**
   - Activated `"integration": true` in `.ci/stages.json`.
   - Wired `python3 scripts/ci/run_checks.py e2e` into CI runner to build frontend, start `serve.py`, wait for readiness, execute Playwright tests, and cleanly shut down child processes.
