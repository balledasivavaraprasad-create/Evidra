## Implemented behavior

1. **Deterministic Baseline Extractor (`backend/app/pico/`):**
   - Implemented `RuleBasedPicoExtractor` and functional entry point `extract_pico_spans()` adhering strictly to the `PicoPort` runtime checkable protocol from D01.
   - Pure functions with zero external network access, zero database writes, and zero LLM dependencies.
   - Extracts Population (P), Intervention (I), Comparator (C), and Outcome (O) phrases directly from original abstract text.
   - Method version: `pico_extractor:v1.0`; rule provenance: `rule:pico:v1.0`.

2. **Zero-Based Half-Open Unicode Code-Point Offsets (`[start_cp, end_cp)`):**
   - Every span computes exact code-point offsets into `abstract_text` where `quote == abstract_text[start_cp:end_cp]`.
   - Never normalizes or modifies text before computing offsets.
   - Handles multi-byte BMP characters (Greek letters `α`, `β`, accents) and non-BMP characters (medical emoji `💉` `\U0001F489`) without offset drift.
   - Implemented bidirectional mapping between Unicode code points and browser DOM / UTF-16 code units (`codepoint_to_utf16_offset`, `utf16_to_codepoint_offset`, `span_codepoint_to_utf16`).

3. **Clinical Invariants & Absence Handling:**
   - Single-arm trials and uncontrolled studies return `has_comparator = False` and no `C` spans.
   - Implemented clinical negation detector `COMPARATOR_NEGATION_REGEX` ensuring mentions such as `"No comparator or control group was included"` are not misattributed as active comparators.
   - Disambiguates repeated mentions (e.g. repeated `"metformin"`), returning separate distinct spans with unique offsets.
   - Handles absent or empty abstracts (`abstract_text is None`) cleanly, returning an empty span list and `has_* = False`.

4. **Domain Validation Engine (`backend/app/pico/validator.py`):**
   - Implemented `validate_pico_result(result, abstract_text)` verifying content SHA-256 fingerprint, span boundary sanity, exact quote slice equality, and boolean flag consistency.

5. **Evaluation Guide & Dev-A Handoff (`evals/pico/`):**
   - Authored `evals/pico/baseline.md` documenting rules, limitations, and exact selection examples with both Unicode code points and browser UTF-16 offsets for the React editor.
   - Authored `evals/pico/eval_pico.py` benchmarking across all 16 canonical synthetic records with 100% slice accuracy and zero validation errors.
