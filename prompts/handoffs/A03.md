## Implemented behavior

1. **Typed Review API Client (`frontend/src/api/client.ts`):**
   - Exported complete endpoints from D03 OpenAPI schema:
     - `api.revisions.list`, `api.revisions.processCorpus`, `api.revisions.listGroups`
     - `api.groups.getDetail`, `api.groups.recordDecision`, `api.groups.savePico`
     - `api.dedup.recordDecision`
     - `api.conflicts.resolve`
     - `api.exports.create`, `api.exports.downloadUrl`

2. **Screening Review Workbench (`frontend/src/features/review-queue/ReviewQueuePage.tsx`):**
   - Real-time group listing by active corpus revision with status filters (All, Include, Exclude, Maybe, Conflict).
   - Optimistic concurrency control using expected row version; handles 409 `STALE_VERSION_CONFLICT` with an in-place reload action while preserving reviewer draft state.
   - Abstract reader with PICO entity highlights, study metadata (DOI, PMID, authors, journal, year), and copy count.
   - Mandatory Exclusion Reason Modal: prohibits empty exclusions, offering standard clinical categories (preclinical animal model, in vitro/simulation, narrative review, wrong population, non-English) and custom text entry.
   - Audit Event Timeline: displays append-only history of reviewer actions, timestamps, and payloads.
   - Sanitized CSV Export: one-click trigger for confirmed included studies with SHA-256 checksum and direct download.
   - On-demand "Process Corpus" action to trigger pipeline recalculation for imported batches.

3. **Exact Unicode PICO Viewer & Annotator (`frontend/src/features/pico/`):**
   - Built `frontend/src/features/pico/offsets.ts` providing exact UTF-16 <-> Unicode code-point mappings (`utf16ToCodePoint`, `codePointToUtf16`, `sliceByCodePoints`, `validateSpanQuote`).
   - Handles multi-byte UTF-8, non-BMP surrogate pairs (emoji/biological symbols), Greek letters, and multiline abstracts without mutating whitespace.
   - Built `frontend/src/features/pico/PicoViewer.tsx` rendering inert text with color-coded semantic highlights (P=Cyan, I=Purple, C=Amber, O=Emerald) and floating selection pill to tag custom spans.
   - Displays missing comparator explicitly as absent ("Comparator: Absent (Single-Arm)").

4. **Deduplication & Disambiguation Panel (`frontend/src/features/duplicates/DuplicatesPage.tsx`):**
   - Side-by-side comparison of candidate records showing title, DOI, authors, and similarity evidence.
   - Action buttons for "Confirm Same Paper" and "Reject (Different Papers)" connected to `api.dedup.recordDecision`, enforcing cannot-link constraints on reject.

5. **Playwright E2E Setup & D04 Contract (`frontend/playwright.config.ts`, `frontend/tests/e2e/level1.spec.ts`):**
   - Created Playwright configuration and test script `test:e2e`.
   - Defined exact test-server contract for D04: API loopback `http://127.0.0.1:8000`, frontend preview `http://127.0.0.1:4173`, readiness checks via `/health/ready`.
   - Vitest configuration in `frontend/vitest.config.ts` isolated to `src/tests/` to prevent collisions with Playwright specs.
