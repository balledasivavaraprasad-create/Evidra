## Implemented behavior

1. **Stage-Specific Input Fingerprinting (`backend/app/workflows/fingerprints.py`):**
   - Implemented `compute_screening_fingerprint(record_id, content_hash, criteria_hash, method_version)`.
   - Implemented `compute_pico_fingerprint(record_id, content_hash, method_version)`.
   - Implemented cache lookup functions `get_cached_machine_result` and `get_cached_pico_annotations`.
   - Criteria changes strictly invalidate screening outputs while preserving PICO extraction reuse.

2. **Incremental Graph Execution (`backend/app/workflows/nodes.py`, `pipeline.py`, `state.py`):**
   - Bumped graph version to `review_graph:v2.0.0` with backward compatibility support for `review_graph:v1.0.0`.
   - Enhanced `ReviewGraphState` with: `mode` ("incremental", "full", "restore"), `restore_snapshot_id`, `reused_screening_count`, `recomputed_screening_count`, `reused_pico_count`, `recomputed_pico_count`, `invalidation_fingerprint`, and `affected_group_ids`.
   - In `process_corpus_node`, reuses existing machine results and PICO annotations when stage fingerprints match, computing only newly added records or changed inputs.
   - Extracts `invalidation_fingerprint` from D05 diff and tracks affected groups across revisions.

3. **Exact Snapshot Restore Bypassing Algorithms (`backend/app/workflows/nodes.py`):**
   - Implemented `restore_snapshot_node` routed directly from `validate_input` when `mode == "restore"`.
   - Restores exact historical corpus snapshot via `restore_corpus_snapshot(db, ws_id, snapshot_id, mode=RestoreMode.EXACT_SNAPSHOT)`.
   - Completely bypasses retrieval, dedup, screening, and PICO nodes; makes 0 algorithm and 0 network/model calls.

4. **Failure Isolation & Atomic Publication:**
   - Any failure during selective processing triggers a full rollback, ensuring `ws.current_revision_id` remains at the last good snapshot without publishing incomplete state or duplicate events.

5. **Level 2 Incremental Graph Test Suite (`backend/tests/level2/test_incremental_graph.py`):**
   - Validated:
     - Unchanged records reuse screening and PICO outputs (reused > 0, recomputed = only new records).
     - Criteria change invalidates screening but preserves 100% PICO reuse.
     - Known source records gain new query membership without redundant source fetches.
     - Exact restore makes zero source/model/algorithm calls and reproduces snapshot.
     - Human decisions and PICO spans remain intact across incremental rerun.
     - Crash/retry during selective processing does not publish incomplete state.
     - Incompatible checkpoint version triggers controlled error.
