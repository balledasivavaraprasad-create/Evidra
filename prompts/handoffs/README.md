# Implementation handoffs

No developer prompt has been implemented by creating this planning package. This folder starts with a [blank handoff template](TEMPLATE.md); copy it to `<ID>.md` only when executing that prompt, for example `D01.md`.

Each developer edits their own ID file. The integration captain reviews prerequisite merge SHAs, tests, interfaces and unresolved requests before accepting the PR. After merging, the captain records the actual merge SHA and updates the root audit at the assigned checkpoint. A filled template without code and verification is not completion evidence.

Follow the [execution/merge order](../EXECUTION-AND-MERGE-ORDER.md) and [task manifest](../tasks.json). Do not confuse their canonical merge position with a recorded merge.
