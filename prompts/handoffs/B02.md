## Implemented behavior

1. **Review Question & Criteria Definition (`backend/app/screening/defaults.py`):**
   - Configured 7 standard review criteria aligned with `docs/review-question.md`:
     1. `population_adults_t2d` (Inclusion, category: "population")
     2. `comparative_clinical_design` (Inclusion, category: "study_design")
     3. `exclude_animal_only` (Exclusion, category: "species")
     4. `exclude_simulation_only` (Exclusion, category: "methodology")
     5. `exclude_case_reports` (Exclusion, category: "study_design")
     6. `english_language` (Inclusion, category: "language")
     7. `abstract_available` (Inclusion, category: "content")
   - Pure function `compute_criteria_hash()` computes deterministic SHA-256 fingerprints of criteria definitions.

2. **Metadata-First, Negation-Aware Screening Rules (`backend/app/screening/rules.py`):**
   - **Species Exclusion (`evaluate_species`):** Evaluates MeSH headings first. Context-aware regex distinguishes pure preclinical animal models (Wistar rats, Sprague-Dawley, rodents) from human clinical trials that mention animal background.
   - **Simulation Exclusion (`evaluate_simulation`):** Separates in silico molecular dynamics/docking without clinical subjects from human clinical trials incorporating pharmacokinetic modeling.
   - **Case Report Exclusion (`evaluate_case_report`):** Evaluates publication types first. Distinguishes single patient case reports from comparative cohorts containing "cases" (e.g., "cohort of 500 cases of type 2 diabetes").
   - **Language Check (`evaluate_language`):** Evaluates language metadata first. Non-English without English fails (`NON_ENGLISH_LANGUAGE`); ambiguous or missing text abstains as `UNKNOWN`.
   - **Population Check (`evaluate_population`):** Evaluates MeSH first. Distinguishes target adult T2D from pediatric Type 1 diabetes (`OFF_TARGET_POPULATION`) with negation awareness.
   - **Study Design Check (`evaluate_study_design`):** Checks publication type metadata first for RCTs/comparative studies before falling back to regex.
   - **Abstract Presence (`evaluate_abstract_presence`):** Detects absent or insufficient abstract text (<30 chars) and yields `UNKNOWN` (`MISSING_ABSTRACT`).

3. **Screening Engine & Decision Aggregation (`backend/app/screening/engine.py`):**
   - Implements `ScreeningEngine` conforming to `ScreeningPort` protocol.
   - Rule aggregation:
     - Any active criterion failure produces `EligibilityStatus.EXCLUDE` with all corresponding reason codes.
     - When all active criteria pass, produces `EligibilityStatus.INCLUDE`.
     - When no criterion fails but one or more active criteria are `UNKNOWN`, produces honest `EligibilityStatus.MAYBE`.
   - Generates reproducible screening fingerprint `compute_screening_fingerprint()` binding record identity, record content hash, criteria version hash, and method version.

4. **Benchmark & Test Suite:**
   - Authored benchmark test set in `evals/screening/fixtures.json` (10 test cases) and runner `evals/screening/run_eval.py`: **100% accuracy, 10/10 correct status and reason codes**.
   - 12 comprehensive unit tests in `backend/tests/algorithms/screening/test_screening.py` testing port conformance, context sensitivity, negation handling, criteria toggling, and fingerprint stability.
