## Implemented behavior

1. **Bounded Review Graph State (`backend/app/workflows/state.py`):**
   - Defined `ReviewGraphState` with bounded identifiers, counts, stages, and error strings.
   - Enforced rule: large abstract texts are never duplicated or held in graph state; only revision/group IDs, version counters, and summary metrics are tracked.
   - Pinned `GRAPH_VERSION = "1.0.0"`.

2. **Deterministic & Human-in-the-Loop Graph Nodes (`backend/app/workflows/nodes.py`):**
   - `validate_input_node`: Validates workspace existence against the business database. Fails gracefully and visibly if workspace is missing.
   - `process_corpus_node`: Executes D03 `process_corpus` deterministic deduplication, screening, and PICO annotation without LLM/network calls. Identifies first group requiring human review (`MAYBE` or `CONFLICT`) if present.
   - `human_review_node`: Issues persistent `langgraph.types.interrupt` payload containing `group_id`, `workspace_id`, and reason. On resumption via `Command(resume=...)`, extracts domain approval and event ID.
   - `finalize_run_node`: Emits observable trace summary with stage/status without leaking private credentials.

3. **Durable Pipeline Builder & Execution Facade (`backend/app/workflows/pipeline.py`):**
   - `build_review_graph`: Compiles StateGraph with conditional edges (`START -> validate_input -> process_corpus -> human_review? -> finalize_run -> END`).
   - `run_review_pipeline`: Runs review pipeline with persistent `SqliteSaver` checkpointer and namespaced thread ID (`review-thread-{workspace_id}`). Supports optional injected session for testing.
   - `resume_review_pipeline`: Reopens SQLite checkpoint from persistent database, passes domain approval payload, and resumes the paused interrupt subgraph.

4. **Integration & Idempotency Testing (`backend/tests/workflows/test_review_graph.py`):**
   - End-to-end execution of seeded fixture corpus without external network or LLM dependencies.
   - Verified that invalid workspaces fail cleanly at the validation stage with observable trace logs.
   - Verified interrupt persistence and resumption across SQLite connection reopen boundaries.
