## Implemented behavior

1. **In-Memory SQLite FTS5 Search Index (`backend/app/retrieval/index.py`):**
   - Implemented `InMemoryCorpusFTSIndex`:
     - Built purely in-memory (`:memory:`) from authorized rows for `(workspace_id, corpus_revision_id)`.
     - Zero mutation of the persistent application database.
     - Enforces hard memory boundaries (`MAX_INDEX_RECORDS = 1,000`, `MAX_INDEX_BYTES = 15 MB`).
     - Extracts search snippets and calculates Unicode code-point offsets `[start_cp, end_cp)`.
   - Implemented `escape_fts_query`:
     - Sanitizes quotes, colons, asterisks, brackets, and SQL/FTS boolean keywords (`AND`, `OR`, `NOT`, `NEAR`).
     - Wraps alphanumeric tokens in double quotes for safe matching, preventing FTS syntax injection.
   - Implemented `CorpusFTSCache`:
     - Thread-safe cache of in-memory indices keyed by `(workspace_id, corpus_revision_id)`.
     - Supports clean invalidation on revision changes.

2. **Bounded Evidence Assistant Service (`backend/app/workflows/assistant.py`):**
   - Implemented `BoundedEvidenceAssistant` conforming to `AssistantPort`:
     - Restricts tasks strictly to allowlist (`explain_screening`, `suggest_query`, `propose_pico`).
     - Scopes retrieval strictly to the authorized `(workspace_id, corpus_revision_id)`.
     - At most ONE controlled query reformulation round if initial retrieval finds 0 chunks.
     - Honest abstention: if no supporting evidence exists or question is out-of-domain, immediately abstains with `proposal_text="Insufficient evidence..."` and 0 citations.
     - Citation verification: validates that every cited handle belongs to retrieved chunks; rejects fabricated or hallucinated citations.
     - Deterministic fallback: if AI is disabled or gateway errors, produces rule-based summary proposal with verified citations.
     - Pure proposal contract: sets `requires_human_approval = True`; zero database commit or write authority.

3. **Unit Test Suites (`backend/tests/retrieval/test_fts_index.py`, `backend/tests/ai/test_assistant_boundaries.py`):**
