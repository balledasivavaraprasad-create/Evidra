## Implemented behavior

1. **Approved-Provider HTTPX Adapter & Protocol Mock (`backend/app/gateway/adapter.py`):**
   - Implemented `HTTPXModelAdapter`:
     - Server-side credentials only (keeps keys out of frontend/logs).
     - Strict task allowlist (`ALLOWLISTED_TASKS = {"pico_extraction", "screening_explanation", "corpus_qa"}`).
     - Strict model allowlist (`ALLOWLISTED_MODELS = {"gemini-1.5-flash", "gemini-1.5-pro", "gpt-4o-mini", "mock-research-model"}`).
     - Payload boundary: rejects context exceeding 50,000 characters with `PAYLOAD_TOO_LARGE`.
     - Token reservation: tracks daily token budget and blocks requests exceeding limits with `BUDGET_EXCEEDED`.
     - Prompt injection defense: scans prompt context using `detect_prompt_injection` and blocks malicious tokens with `INJECTION_DETECTED`.
     - Network resilience: handles provider timeouts (`TIMEOUT`), HTTP 429 (`RATE_LIMITED`), and 5xx (`PROVIDER_ERROR`) with at most 1 bounded retry before failing closed.
   - Implemented `MockModelAdapter`:
     - Protocol-compliant deterministic mock adapter for offline testing and CI verification without requiring external network calls or API keys.

2. **Validated LLM PICO Extraction Service (`backend/app/pico/llm.py`):**
   - Implemented `LLMPicoExtractor`:
     - Accepts immutable abstract text and produces `PicoResult` conforming to `PicoPort`.
     - Validates every quote and Unicode code-point offset: verifies `abstract_text[start_cp:end_cp] == quote`.
     - Detects forged or fabricated citations and discards them.
     - Resolves missing offsets automatically if quote appears uniquely in abstract text.
     - Detects repeated-quote ambiguity: requires exact matching offsets when identical terms appear multiple times.
     - At most ONE repair request is dispatched to the gateway if errors are detected; if repair fails or returns invalid spans, seamlessly falls back to `RuleBasedPicoExtractor`.
     - Fail-closed behavior: if LLM is disabled (`LLM_ENABLED=false`) or credentials are absent, immediately executes deterministic rule extractor without error.
