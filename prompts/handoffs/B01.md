## Implemented behavior

1. **Metadata & String Normalization (`backend/app/dedup/normalization.py`):**
   - Implemented DOI normalization: strips `https://doi.org/`, `http://dx.doi.org/`, and `doi:` prefixes, converts to lowercase, trims whitespace.
   - Implemented PMID normalization: extracts canonical digit strings.
   - Implemented title normalization: Unicode NFKD normalization, lowercase, punctuation removal, whitespace compaction. Preserves semantic numbers.
   - Implemented author token extraction: extracts surname and initials for resilient author matching.
   - Implemented trial registry extraction: regex matching for ClinicalTrials.gov NCT IDs (`NCT\d{8}`) and ISRCTN (`ISRCTN\d{8}`).
   - Implemented study design / protocol classifier: identifies protocols, design papers, and rationale reports to maintain study vs publication separation.

2. **Deterministic Pairwise Candidate Matching (`backend/app/dedup/matcher.py`):**
   - Implemented multi-key candidate blocking and deterministic pair generation (`find_candidate_pairs`).
   - Rule 0: Contradictory strong identifiers (distinct non-null DOIs or distinct non-null PMIDs) immediately abstain—never propose as duplicates.
   - Rule 1: Clinical study vs publication separation: companion reports sharing a clinical trial NCT ID where one is a study protocol and another is trial results are recognized as distinct publications of the same study, preventing false duplicate merges.
   - Rule 2: Exact identifier matching for consistent DOIs/PMIDs yields 1.0 confidence proposals with structured evidence.
   - Rule 3: Exact normalized title matching requires author overlap or year agreement (+/-1 year) to prevent generic title false positives.
   - Rule 4: Multi-field fuzzy matching combines token sort ratio (>=90) with independent author overlap or year proximity, producing calibrated provisional scores (0.75-0.95).

3. **Partitioning & Cannot-Link Graph Enforcement (`backend/app/dedup/partitioner.py`):**
   - Implemented connected-component graph partitioning using Union-Find (`partition_groups`).
   - Strictly enforces negative reviewer feedback (`cannot_link_pairs`) across transitive paths: if record A is cannot-link with C, edge A-B and edge B-C cannot merge into a single component.
   - Deterministic representative selection (`select_group_representative`): prioritized by (1) presence of abstract text, (2) completeness of metadata (DOI, PMID, journal, pages, year), (3) PubMed canonical source preference, and (4) stable alphanumeric record ID. Never depends on wall-clock time or arrival order.

4. **Public Facade (`backend/app/dedup/__init__.py`):**
   - Exposes `DeduplicationEngine` conforming to `DeduplicationPort` protocol.
   - Provides pure, side-effect-free methods `propose_candidates()` and `partition_groups()`.

5. **Evaluation Benchmark & Verification Suite:**
   - Authored pairwise evaluation dataset in `evals/dedup/benchmark.json` covering exact DOI copies, author variants without DOIs, protocol vs results negatives, primary vs follow-up negatives, and distinct animal studies.
   - Authored evaluation runner `evals/dedup/run_eval.py`: 100% precision, 100% recall, 0 study-vs-paper false merges.
   - 9 comprehensive unit tests in `backend/tests/algorithms/dedup/test_dedup.py` verifying port conformance, identifier rules, permutation invariance, cannot-link enforcement, and representative selection.
