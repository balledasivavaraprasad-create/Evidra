**Question:** In adults with type 2 diabetes, how does metformin, compared with placebo or another glucose-lowering intervention, affect HbA1c?

| PICO | Provisional value |
|---|---|
| Population | Adults with type 2 diabetes |
| Intervention | Metformin |
| Comparator | Placebo or another glucose-lowering intervention |
| Outcome | Change in HbA1c |

| Criterion | Inclusion/exclusion and reason | Metadata first | Missing/unclear evidence |
|---|---|---|---|
| Population | Human adults with relevant condition; matches question | MeSH/subject metadata if provided | Text evidence; mixed ages/species → Maybe |
| Design | Comparative clinical studies able to address question | Publication type | Explicit methods/arms evidence; absence of label is not exclusion |
| Animals | Exclude animal-only studies; different population | Species/MeSH | Negation-aware text evidence; mentions of animal background alone insufficient |
| Simulation | Exclude simulation-only studies; no measured patient outcomes | Study type if available | Require explicit simulation-only evidence; human analysis using models is not automatically excluded |
| Language | English-reviewable material for team capacity | Language list | Short/ambiguous language detection → Maybe, not confident exclusion |
| Case report | Exclude single case reports; not group comparison | Publication type | Explicit case-report pattern; “cases” alone is not enough |
| Abstract availability | Missing abstract needs manual review | Abstract field | Mark Maybe / needs full text; preserve record |

Reviewer can toggle criteria and must version the change. Dates are search settings, not an unstated eligibility rule. Report whether exclusions used metadata, text rules or human review. Confirm whether conference abstracts, reviews, protocols and observational designs belong before coding topic rules; do not silently add exclusions.
